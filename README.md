# Портфолио Алексея Валькова

Персональный сайт с кейсами fullstack-разработки, веб-инструментов и автоматизации.

## Запуск

```bash
npm install
npm run dev
```

Проект откроется на `http://localhost:3000`.

## Проверка

```bash
npm run lint
npm run build
```

## Контент

Профиль, проекты, отзывы и описания кейсов находятся в `src/data/site.ts`.
Изображения проектов — в `public/projects`.

Для корректных canonical URL, sitemap и социальных превью при публикации задайте:

```env
NEXT_PUBLIC_SITE_URL=https://example.com
```
